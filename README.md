# DJNote

DJNote helps DJs organize music, analyze track metadata, plan sets, and keep performance notes in one place.

This public repository contains DJNote documentation and downloadable release builds. The application source code is maintained privately.

## Features

- Track library management for DJ collections
- BPM, key, energy, mood, and genre-focused organization
- Harmonic mixing support using Camelot-compatible key matching
- DJ set and session planning
- Import/export workflows for library and set data
- Account sync across supported devices
- Free and premium app tiers

## Repository Scope

This repository is intentionally public and limited to:

- User-facing documentation
- Release notes
- Public screenshots and branding assets
- Downloadable release binaries

Private source code, service configuration, signing material, database internals, and development documentation are not published here.
